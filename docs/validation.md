# 빌드·검증·조사 범위

## 빌드 순서

```powershell
py -3.13 tools/build_release.py <버전>   # 폰트 + 텍스트 + 이미지 → build/<버전>/
py -3.13 tools/verify_build.py <버전>    # 재읽기 검증
py -3.13 patcher/build_steam_pack.py <버전> build/<버전>
py -3.13 patcher/build_package.py <버전>
```

`build_release.py`는 항상 **검증된 원본**(`backup/original/`)을 입력으로 씁니다. 개발 중 게임 폴더에 설치한 빌드를 다시 입력으로 읽지 않도록 한 것입니다. 폰트·텍스트·이미지가 같은 엔트리를 동시에 바꾸려 하면 빌드를 멈춥니다.

## 검증 기록 (v20260927)

**빌드 재읽기** — `verify_build.py`

- 교체 엔트리 1,163개, 바뀌지 않은 엔트리 859개는 원본과 바이트 동일.
- 언어 파트가 쓰지 않는 ID의 레코드는 원본과 동일.
- 한국어 문자열 81,570개를 완성본에서 다시 읽어 빌드 입력과 불일치 0.
- 미번역 목록 0건.

**팩** — `build_steam_pack.py`

- 원본 + 팩만으로 재구성한 `LINKFILE_CHS.BIN`의 SHA-256이 완성본과 일치.
- 같은 입력으로 다시 만든 팩의 SHA-256이 같음(결정적 빌드).

**패처** — 게임 폴더 사본에서 실행

- 상태 검사(원본) → 패치 → 결과 두 파일이 빌드 결과와 바이트 동일.
- 이미 적용된 상태에서 다시 실행 시 쓰지 않음.
- 원본 복구 → 원본 해시 일치 → 재패치 성공.
- 이전 버전 팩으로 적용한 상태에서 새 버전 적용 → 이전 버전 감지, 원본 재구성, 새 버전 적용 해시 일치.

**배포물**

- ZIP 재추출 파일 해시가 패키지 폴더와 일치.
- 릴리즈에서 내려받은 ZIP의 SHA-256이 빌드 결과와 일치.

## 게임 화면 확인

개발 중 설치본으로 메인 메뉴, 전투 준비, 헤더 이미지, 모드 설명, 2P 안내, 텍스트 렌더링과 자간을 게임 화면에서 확인했습니다. 모든 화면을 확인한 것은 아닙니다. 파일 검증(해시 일치)은 번역 품질이나 모든 화면의 배치를 보증하지 않습니다.

## 조사 범위

- 언어 파트에서 언어마다 그림이 다른 텍스처 1,047개를 분류했습니다. 일부 썸네일·고지 화면은 [알려진 문제](known-issues.md)에 남겨 두었습니다.
- 실행 파일은 폰트 코드표를 읽기만 하고 수정하지 않습니다.
- 공통 파트(`LINKFILE_000~003`)의 텍스처는 교체하지 않습니다.
