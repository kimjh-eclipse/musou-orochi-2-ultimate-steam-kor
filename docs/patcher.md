# 패처·재구성·백업

`patcher/WO3USteamPatch.cs`(C# 5, .NET Framework 4.x, WinForms)는 PS3판 빠른 패처와 같은 화면 흐름을 씁니다. 설치 경로 → 백업 경로 → 주의사항 동의 → 상태 검사·패치·복구 순서이며, 같은 기능을 명령줄로도 쓸 수 있습니다.

## 재구성 방식을 쓴 이유

한국어 `LINKFILE_CHS.BIN`은 교체 항목의 크기가 바뀌어 뒤 항목 오프셋이 모두 달라집니다([아카이브 구조](formats.md)). 원본과 완성본을 바이트 단위로 비교하면 파일 대부분이 달라지므로, PS3판처럼 바뀐 구간만 덮어쓰는 방식은 쓸 수 없습니다.

대신 패처가 **완성본 인덱스 순서대로 파일을 새로 씁니다.**

```text
for id in 완성본 IDX의 사용 항목 (완성본 오프셋 순):
    0으로 완성본 오프셋까지 채움
    if id 가 팩에 있음: 팩의 저장 바이트
    else:               사용자 원본 LINKFILE 의 같은 id 저장 바이트
0으로 완성본 파일 크기까지 채움
```

바뀌지 않은 항목은 사용자의 게임 파일에서 복사하므로, 배포 팩에는 한국어로 바뀐 항목(1,163개)만 들어갑니다.

## 팩 형식: WO3USTM1

정수는 리틀 엔디언입니다.

```text
8 bytes  magic = "WO3USTM1"
i32      format_version = 1
u16 + B  release (UTF-8)
2 x      파일 레코드 (LINKIDX_CHS.BIN, LINKFILE_CHS.BIN):
  u16 + B  이름
  u64      원본 크기     32 B 원본 SHA-256
  u64      완성본 크기   32 B 완성본 SHA-256
u32 + B  완성본 LINKIDX_CHS.BIN 전체
u32      항목 수
각 항목 (id 오름차순):
  u32 id   u64 길이   저장 바이트(압축 상태 그대로)
```

리더는 파일 순서·인덱스 크기·항목 순서·범위·팩 끝의 남는 데이터를 검사합니다.

## 상태 판별

두 파일의 크기로 원본/완성본 후보를 먼저 가리고, SHA-256으로 확정합니다.

| 상태 | 조건 | 동작 |
|---|---|---|
| 원본 | 두 파일 모두 원본 해시 | 패치 가능 |
| 완성본 | 두 파일 모두 이 버전의 완성본 해시 | 다시 쓰지 않음 |
| 이전 버전 | 지정한 백업이 기록한 완성본 해시와 일치 | 백업으로 원본 재구성 후 새 버전 적용 |
| 알 수 없음 | 그 밖 | 중단, Steam 무결성 검사 안내 |

## 백업 형식: WO3USBK1

백업에는 **원본에서 교체되는 항목의 원본 저장 바이트**와 원본 인덱스만 저장합니다(이번 버전 약 300MB). 원본 파일 전체를 복사하지 않습니다.

```text
8 bytes  magic = "WO3USBK1"
i32      format_version = 1
u16 + B  백업을 만든 패치 버전
2 x      파일 레코드 (팩과 같은 구조: 원본·완성본 크기와 해시)
u32 + B  원본 LINKIDX_CHS.BIN 전체
u32      항목 수, 각 항목: u32 id, u64 길이, 원본 저장 바이트
```

복구는 같은 재구성을 반대 방향으로 합니다. 현재(완성본) 파일과 원본 인덱스를 기준으로, 백업에 있는 항목은 백업에서, 나머지는 현재 파일에서 가져와 원본을 만듭니다. 백업이 기록한 완성본 해시와 현재 파일이 같을 때만 복구합니다.

## 쓰기 순서

1. 게임 실행 여부(`WO3U.exe`), 여유 공간, 쓰기 권한을 확인합니다. Program Files처럼 권한이 없으면 관리자 권한으로 다시 실행할지 묻습니다.
2. 백업을 `.tmp`로 쓰고 구조를 다시 읽어 확인한 뒤 이름을 바꿉니다.
3. 새 `LINKFILE_CHS.BIN`을 `.wo3u-new`로 쓰면서 SHA-256을 계산합니다. 완성본 해시와 다르면 임시 파일을 지우고 중단합니다.
4. 새 인덱스도 `.wo3u-new`로 씁니다.
5. 두 파일을 교체합니다. 기존 파일은 `.wo3u-old`로 옮겼다가 교체가 끝나면 지웁니다. 도중에 실패하면 `.wo3u-old`로 되돌립니다.
6. 교체 후 두 파일 해시를 다시 확인합니다. 어긋나면 백업으로 원본을 재구성합니다.

## 명령줄

```text
WO3U_Steam_KR_Patch.exe [--folder <설치 폴더>] [--backup <백업 파일>]
                        [--verify-only | --restore] [--yes] [--no-pause]
```

`--folder`를 생략하면 Steam 설치 폴더를 자동으로 찾습니다. 종료 코드는 성공 0, 실패 1, 상태 검사에서 알 수 없는 상태 2입니다.

## 빌드

```powershell
py -3.13 patcher/build_steam_pack.py <버전> build/<빌드>     # 팩 + 재구성 자가검증
py -3.13 patcher/build_package.py <버전>                     # csc → 패키지 → ZIP → 재추출 대조
```

`build_steam_pack.py`는 팩을 쓴 뒤 원본과 팩만으로 완성본을 다시 만들어 해시를 대조하고, 어긋나면 실패로 끝납니다.
