## 직접 계산하기

현재 디렉터리가 설치 폴더일 때:

```powershell
Get-FileHash .\LINKIDX_CHS.BIN -Algorithm SHA256
Get-FileHash .\LINKFILE_CHS.BIN -Algorithm SHA256
Get-FileHash .\dinput8.dll -Algorithm SHA256
```
