# 이미지 처리

메뉴 제목, 스테이지 타이틀, 무장 이름, 로딩 화면 등 글자가 그림으로 들어간 곳은 텍스트 번역으로 바뀌지 않습니다. 언어 파트의 G1T 텍스처 중 언어판마다 그림이 다른 것을 찾아, 중국어 글자를 지우고 한국어로 다시 그렸습니다.

이번 릴리즈는 **688개 엔트리, 1,023개 텍스처**, 라벨 약 2,650개를 교체합니다.

## G1T (PC)

| 형식 코드 | 픽셀 형식 |
|---|---|
| `0x01` | RGBA8 |
| `0x59` | BC1(DXT1) |
| `0x5B` | BC3(DXT5) |

PC판 G1T는 리틀 엔디언이고 확인한 텍스처는 모두 밉맵 1단입니다. `tools/g1t_pc.py`가 디코드·인코드·교체를 맡고, BC1/BC3 인코딩은 Pillow의 DDS 인코더를 씁니다. 교체 후 다시 디코드해 크기와 형식이 원본과 같은지 확인합니다.

## 대상 찾기

`tools/image_diff_textures.py`로 같은 ID의 텍스처를 네 언어판에서 비교해, 언어마다 그림이 다른 텍스처 1,047개를 목록으로 만들었습니다. 목록을 대조표 88장으로 모아 눈으로 분류했습니다.

## 교체 스펙

교체 내용은 이미지별 JSON(`mapping/images/<엔트리>.json`)으로 기록하고, `tools/build_images.py`가 빌드 때 적용합니다. 스펙은 텍스처 번호와 라벨 목록(영역, 한국어, 그리는 방식)을 담습니다. 스펙은 생성 스크립트(`tools/spec_*.py`)로 만듭니다.

## 라벨 다시 그리기

`tools/image_labels.py`는 원래 라벨의 모양을 따라 한국어를 그립니다.

- **영역**: 알파 채널에서 글자 덩어리를 찾아 줄·단어별 상자를 만듭니다(`tools/label_boxes.py`, `tools/cc_boxes.py`).
- **스타일 추출**: 원래 글자에서 채움 그라데이션(밝은 픽셀 상위 30%의 행별 색), 테두리색, 글로우색·세기를 뽑습니다.
- **글꼴**: 제목류는 Noto Serif KR(굵기 800, 기울기 0.14), 작은 UI는 Noto Sans KR. 원본처럼 첫 글자를 크게 쓰는 제목 양식(`first_big`)을 지원합니다.
- **맞춤**: 상자 높이에 맞춰 크기를 정하고, 넘치면 가로로 70%까지 좁힌 뒤 그래도 넘치면 줄입니다.

글자를 지우는 방식은 배경에 따라 고릅니다.

| 방식 | 쓰는 곳 |
|---|---|
| 상자 비우기 | 투명 배경의 라벨 |
| `ink` | 장식(날개·붓자국) 위 글자: 불투명한 글자와 테두리만 지움 |
| `rowfill` | 버튼·태그 면 위 글자: 글자 구간을 좌우 버튼 색으로 한 줄씩 다시 칠함 |
| `bright` | 톱니 아이콘 위 글자: 밝은 글자만 주변 색으로 채움 |
| `solid` | 검은 인트로 화면: 배경색으로 칠함 |

## 계열별 처리

- **스테이지·이벤트·지명 타이틀 372장**: PS3판 v19 타이틀 카탈로그와 그림을 대조해, PC 엔트리 번호가 PS3 번호에서 일정하게 떨어져 있음을 확인했습니다(−283/−357/−1176). PS3판의 번역을 그대로 씁니다.
- **무장 이름 아틀라스**: 캐릭터 순서(텍스트 엔트리 33의 무장 목록)를 따르는 격자는 순서대로 넣고, 자기 순서로 배치된 아틀라스는 칸 모양 대조(`tools/match_names.py`) 후 약한 대응을 확대 화면으로 확인했습니다.
- **로딩 화면 무장 이름 290장**: 불투명한 그림 위에 이름이 있고 모든 언어판의 같은 자리에 글자가 있어 원 배경을 복원할 수 없습니다. 글자 영역을 가로 방향으로 번지게 채우고 가장자리를 부드럽게 섞은 뒤 한글을 씁니다(`tools/image_overpaint.py`).
- **타이틀 로고**: 타이틀·로딩·배경화면의 중문 로고를 PS3판 한국어 로고로 바꿉니다(`tools/image_logo.py`).
- **언어 중립 그림**: 일본어판이 영어·기호만 쓰는 그림(Clear!, EMPTY, COMBO!, Power 등)은 일본어 슬롯의 그림을 그대로 가져옵니다.

## 시작 경고 화면

게임 시작 시 나오는 저작권 경고(CHS 엔트리 14753 t0, 2048×2048 RGBA8, 유효 영역 1920×1080)를 한국어로 다시 그렸습니다(`tools/boot_notice.py`, `mapping/images/14753.json`). 이 텍스처는 채널이 BGRA 순서로 저장되어 있어 이 렌더러에서만 R/B를 바꿔 처리합니다.
