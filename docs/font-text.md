# 한글 인코딩·폰트

중국어 간체 슬롯은 GBK 코드로 문자를 찾아 폰트 아틀라스의 칸을 그립니다. 엔진에 새 문자 코드를 추가하지 않고, **한자 칸 하나에 한글 한 글자를 배정**하는 방식으로 한글을 표시합니다. 중국어 표시는 사라지지만 한국어 전용 슬롯으로 쓰기 때문에 문제가 되지 않습니다.

## 폰트 아틀라스

| 항목 | 값 |
|---|---|
| 위치 | CHS 파트 엔트리 38, G1T 텍스처 |
| 형식 | BC3(DXT5), 4096×8192, 밉맵 1단 |
| 칸 | 48×48 픽셀, 가로 85칸 |
| 코드표 | `WO3U.exe` 안 u16 배열 9,888개(파일 오프셋 `0xB936EE`) |

칸 번호 `k`의 문자 코드는 코드표의 `k+1`번째 값입니다. 이 대응은 아틀라스의 칸 그림과 코드표를 대조해 정했습니다(`tools/find_glyph_table.py`, `tools/verify_cellmap.py`). 실행 파일은 수정하지 않습니다.

## 한글 배정

코드표에서 GBK 한자인 칸(GB2312 `B0A1–F7FE`와 GBK 확장) **9,434개**를 한글 자리로 씁니다. 기호 행(`A1–A9`, 가나·전각 문자 포함), 사용자 정의 `AAxx`, ASCII는 그대로 둡니다.

칸이 찰 때까지 다음 순서로 문자를 고릅니다(`tools/ko_charset.py`).

1. 번역문에 쓰인 한글
2. KS X 1001 완성형 2,350자
3. 호환 자모 ㄱ–ㅣ
4. 코드표에 없는 기호(・ ＊ ♪)
5. 나머지 음절(자주 쓰는 받침 먼저)

결과는 한글 **9,380음절**과 그 밖의 문자 54개입니다. 고른 문자를 코드 포인트 순으로 정렬해 한자 칸에 코드 오름차순으로 배정합니다. 대응표는 `mapping/ko_charset.json`에 있으며, 같은 한글은 모든 텍스트에서 같은 코드로 인코딩됩니다. ASCII(제어 코드·서식 토큰·줄바꿈 포함)는 그대로 통과합니다.

인코더(`tools/ko_encode.py`)는 배정되지 않은 문자를 만나면 빌드를 멈춥니다. 번역 병합 단계에서도 같은 검사를 하므로 표시되지 않는 글자가 게임에 들어가지 않습니다.

## 글리프 그리기

`tools/build_font.py`가 배정된 칸만 다시 그립니다.

- 글꼴은 Noto Sans KR(Medium), 47px, 칸 중앙 기준(anchor `mm`)입니다.
- 글자가 칸 밖으로 나가면 크기를 줄여 다시 그립니다. 이번 빌드에서 칸을 벗어난 글자는 없습니다.
- BC3 블록 중 알파 부분만 새 글리프로 인코딩하고, 색 부분은 흰색으로 둡니다. 엔진이 알파를 글자 모양으로, 색을 텍스트 색으로 쓰기 때문입니다.

## 줄바꿈과 폭

엔진은 긴 문장을 자동으로 줄바꿈하지 않는 칸이 있습니다. 일본어 원문이 손으로 줄을 나눈 곳(듀얼 모드 비기 카드 설명 등)은 한국어에 맞게 다시 나눴습니다. 카드 설명은 한 줄 10자(공백은 0.5자), 최대 5줄 기준으로 어절 단위 줄바꿈을 합니다.
